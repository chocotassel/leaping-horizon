# Evidence-grounded song direction before level compilation

Status: Accepted. The offline pipeline first converts measured audio analysis into an immutable `DirectedSongScore` containing Musical Anchors, Scenes, Phrase Identities, lane-independent Kinetic Forms, Directed Moments, Color Scenes, and Visual Accents; a deterministic compiler then realizes those intentions as playable rows and records a cue-to-output `RealizationReceipt`. This keeps models and detectors away from low-level obstacle JSON, makes every strong transition auditable, preserves exact repeated phrases unless development is explicit, and treats named gestures as optional vocabulary instead of song-length quotas. The trade-off is a larger generated artifact and a stricter compiler contract, but generation remains reproducible without manual annotation or a network model, while future transcription or multimodal-model adapters can enrich the Director Score without changing gameplay invariants.
